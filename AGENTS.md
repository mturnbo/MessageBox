# Project Summary

This project aims to develop a simple messaging system with API's and frontend UI's in multiple languages.

# Code standards and guidelines

1. Use PM2 to manage processes
2. Simpler is better
3. Use meaningful variable names
4. Follow the DRY principle
5. Write modular and reusable code
6. Use version control (e.g., Git)
7. Write clear and concise documentation, no emojis
8. Test code thoroughly
9. Follow security best practices
10. Keep your dependencies up to date
